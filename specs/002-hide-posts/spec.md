# Feature Specification: 隐藏指定博客文章（保留源文件）

**Feature Branch**: `002-hide-posts`  
**Created**: 2026-05-12  
**Status**: Draft  
**Input**: User description: "我想要增加一个功能，保证有些博客可以不显示，但是不删除源文件"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 访客仅能看到公开文章 (Priority: P1)

作为站点访客，我在浏览首页/列表/归档/标签等页面时，只能看到公开发布的文章；被隐藏的文章不应出现在任何公开入口中。

**Why this priority**: 避免未准备好的内容被意外曝光，是最直接的用户价值与风险控制。

**Independent Test**: 选取一篇标记为“隐藏”的文章，验证其不会出现在公开列表与聚合页面中，同时其他文章展示不受影响。

**Acceptance Scenarios**:

1. **Given** 某篇文章被标记为隐藏，**When** 访客访问首页与文章列表页，**Then** 该文章不出现在任何列表条目中
2. **Given** 某篇文章被标记为隐藏且带有标签/分类等信息，**When** 访客访问对应标签/分类/归档页面，**Then** 该文章不出现在聚合结果中

---

### User Story 2 - 维护者无需删除文件即可隐藏/恢复文章 (Priority: P2)

作为博客维护者，我希望能通过为文章设置“隐藏”状态来控制其是否公开展示，并且不需要删除或移动源文件，以便后续继续编辑与恢复发布。

**Why this priority**: 保留内容资产与编辑流程，降低维护成本；同时确保“隐藏”是可逆操作。

**Independent Test**: 将一篇文章从公开切换为隐藏并验证其消失；再从隐藏切换为公开并验证其恢复。

**Acceptance Scenarios**:

1. **Given** 一篇公开文章存在且可在列表中看到，**When** 维护者将其设置为隐藏，**Then** 该文章不再出现在任何公开入口中
2. **Given** 一篇隐藏文章存在，**When** 维护者将其恢复为公开，**Then** 该文章重新出现在相应列表与聚合页面中

---

### User Story 3 - 隐藏文章不可通过直接链接被访问 (Priority: P3)

作为站点访客，即使我知道隐藏文章的直接链接地址，也不应能够打开其内容页面。

**Why this priority**: 避免“仅从列表隐藏但仍可直达”的信息泄露风险。

**Independent Test**: 对隐藏文章的详情页地址发起访问，验证不会返回文章内容。

**Acceptance Scenarios**:

1. **Given** 一篇文章被标记为隐藏，**When** 访客访问该文章的详情页地址，**Then** 页面不展示文章内容并表现为“未找到/不可用”

---

### Edge Cases

- 当文章未显式设置“隐藏/公开”状态时，系统默认将其视为公开
- 当隐藏文章仍被其他文章/页面链接引用时，访客点击后应表现为“未找到/不可用”
- 当隐藏文章曾经公开过且可能被搜索引擎收录时，访客通过旧链接访问应表现为“未找到/不可用”

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 支持对单篇文章设置“隐藏/公开”状态，用于控制其是否对访客可见
- **FR-002**: 被标记为隐藏的文章 MUST 不出现在任何面向访客的文章集合中（例如：首页列表、分页列表、归档、标签/分类聚合、站点内搜索结果、订阅聚合等如存在）
- **FR-003**: 被标记为隐藏的文章 MUST 不可被访客通过其详情页地址访问到正文内容（应呈现为“未找到/不可用”）
- **FR-004**: 启用隐藏后，文章源文件 MUST 保持在仓库中，不被删除、不要求移动到其他目录
- **FR-005**: 将文章从隐藏切换回公开后，系统 MUST 使其重新参与公开列表与聚合展示
- **FR-006**: 当文章未设置状态字段时，系统 MUST 将其默认为公开，以避免误隐藏既有内容

### Key Entities *(include if feature involves data)*

- **Post**: 单篇博客文章；包含标题、日期、正文内容以及“隐藏/公开”状态等元信息
- **Visibility State**: 描述文章在公开站点中的可见性状态（公开或隐藏）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对于被设置为隐藏的文章，在首页/列表/聚合页面的展示结果为 0 条出现（抽检至少 10 篇隐藏文章）
- **SC-002**: 访问任意隐藏文章的详情页地址，文章正文内容泄露率为 0（抽检至少 10 个隐藏文章链接）
- **SC-003**: 维护者将一篇文章从公开切换为隐藏后，在公开入口中不可见的生效时间不超过 1 分钟（以一次完整发布流程计）
- **SC-004**: 维护者将一篇文章从隐藏恢复为公开后，能在公开入口中再次看到该文章，成功率达到 100%（抽检至少 10 次切换）

## Assumptions

- 维护者能够编辑文章的元信息（例如标题、日期等现有字段），不要求提供额外的可视化后台界面
- v1 仅覆盖“公开站点展示与访问控制”，不包含基于登录用户的差异化可见性
- 文章的权威来源仍为仓库内 `posts/` 目录下的 Markdown 文件
